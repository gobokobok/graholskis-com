# graholskis.com

Astro 6 + Tailwind 4 + MDX. Static build, deployed on Railway.

Design: "Monochrome Console" — tokens and components live in `src/styles/global.css`.
Fonts: Inter (text) and Fragment Mono (labels, numbers).

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in ./dist
npm run preview  # serve the build
```
